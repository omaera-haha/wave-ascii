# AGENTS.md

This file provides guidance to coding agents such as Codex when working with code in this repository. It mirrors CLAUDE.md; keep the two in step.

## Overview

`wave-ascii` is a Rust (edition 2024) terminal app in which a ghost lives in a glass box. The box is a 3D room drawn as text (dots, dashed edges, a lamp, a plant, a ball, toy blocks, a cushion, drifting light motes). The ghost is a point with a body, needs, a mood, and a plan, drawn as an abstract shape of dots whose glow and face show its state. Two models give it a mind: Jev (TypeSafe's System One model) picks what it does next, and Claude (System Two) reflects, sets goals, remembers, and talks. Without keys it runs on instinct. Dependencies: `crossterm` (terminal), `glam` (math), `tokio` and `reqwest` (API calls), `serde`/`serde_json`, `jiff` (local time), `unicode-width` (wide characters).

## Commands

The Rust toolchain lives in the dev container (`.devcontainer/`, based on `rust:latest`, which adds rustfmt and clippy). The host may not have `cargo` installed.

```bash
cargo check
cargo test
cargo test world::tests::      # one module's tests
cargo fmt --check
cargo clippy --all-targets
cargo run --release            # interactive; --style, --color, --fps, --offline, --help
```

When stdin or stdout isn't a terminal, the app prints one frame of a fresh, seeded ghost and exits. It never touches saved files or models. The frame size comes from `COLUMNS`/`LINES`. `--time` runs the world that long first (instinct decides), `--hour` sets the time of day (default 12), `--date YYYY-MM-DD` sets the date (default 2026-06-21), and optional `--born YYYY-MM-DD` sets its birth date for birthday previews, so a given `--time`/`--hour`/`--date`/`--born` always gives the same frame:

```bash
COLUMNS=100 LINES=32 cargo run -q -- --time 20 < /dev/null | cat
COLUMNS=100 LINES=32 cargo run -q -- --style blocks --color truecolor --hour 21 < /dev/null | cat
COLUMNS=100 LINES=32 cargo run -q -- --date 2026-12-24 --hour 22 --time 400 < /dev/null | cat
COLUMNS=100 LINES=32 cargo run -q -- --date 2027-03-01 --born 2026-03-01 < /dev/null | cat
```

To exercise the interactive loop, run it under `script` with a pty and feed input on stdin. Point `XDG_CONFIG_HOME`, `XDG_DATA_HOME`, and `HOME` at a scratch directory so the real save isn't touched, for example `(sleep 1; printf q) | XDG_DATA_HOME=/tmp/x XDG_CONFIG_HOME=/tmp/x HOME=/tmp/x script -qfec "stty rows 34 cols 110; ./target/release/wave-ascii" /dev/null`. Feed mouse input as SGR reports with 1-based cells: `printf '\033[<35;50;12M'` moves the pointer to column 50, row 12; `'\033[<0;50;12M'` and `'\033[<0;50;12m'` press and release the left button; `'\033[<32;55;12M'` drags; `'\033[<64;50;12M'` scrolls.

No API keys are available in the dev container; the clients and the mind are tested against local mock servers.

## Architecture

Each frame: `App::advance` steps the `World` and lets the `Mind` act on it, then `App::frame` builds the face, aura, and pose, calls `render::render` (a `Frame`), turns it into a `Canvas` with `Style::canvas`, and `ui::draw` adds words and panels. `Terminal::draw` writes the changed cells.

- **`world/`** is the simulation, deterministic for a seed (`Random`, SplitMix64). The room is the box `ROOM_MIN`..`ROOM_MAX`, floor at y = 0, glass front facing +z. `World::step` moves in slices of at most 0.1 s: motes drift, spawn, and expire; the ball rolls and bounces or follows the ghost while held; the plant gets thirsty; the ghost carries out its `Plan` (`carry_out`), steers toward the plan's target around obstacles and away from walls (`move_ghost`), and its `Needs` (energy, fun, company, 0 to 1) change. Its `Mood` comes from a mind's suggestion while it holds, otherwise from needs and recent events (`feeling`). `Activity` is what a plan does (float, explore, chase, rest, play, tend, lamp, visit, window, fetch, dance, hide, doodle, pounce, game, wait, build); minds only choose one through `begin`, from `options()` (what makes sense now), and `describe` words each option. Viewer actions are methods: `poke`, `pet`, `drop_mote`, `kick_ball`, `nudge_block`, `hear`, `point_at`, `challenge`, `mark`. `pet` takes how far a stroke moved across the ghost; petting fades within seconds, soothes it to cheerful, adds company, slows its movement, makes the face blissful and puff hearts, never wakes a sleeper, finds a hidden ghost, and records `Petted` once per spell. `vocabulary.rs` reads a message's tone (greeting, farewell, praise, or a no, in English and Korean) and its other words, and keeps the `Vocabulary` (saved in `Life`): evidence for what each word means, learned from the activity the ghost was doing when it heard the word, what the viewer did next (a ball flick means fetch, a dropped mote chase), praise or a no after it acted on the words, and `heed` (a mind's request routing); a word means an activity once its evidence is strong and clear. `introduced_name` recognizes English and Korean introductions without a model, keeps the viewer's name in `Life::viewer_name`, and records `LearnedName` with a first-name milestone; introductions do not teach activity words. `hear` returns a `Heard` (tone, `Understanding`, words and viewer name just learned) and acts on a known word if it can, else comes to the glass; a no stops the current plan. `guess` tries out what a repeated unknown word might mean. `question.rs` recognizes simple questions about the ghost (feeling, doing, name, the viewer's name, liking, age, favorite, weather, tired, hungry, bored, lonely, shelf, bird; English word runs and Korean pieces, some needing a question mark); `hear` then returns `Understanding::Asked` with what it was doing (or `None` if asleep), learns nothing from the words, ignores praise words in them, and comes to the glass; `musing::reply` answers from the ghost's state (in Korean when `Heard::korean`), and the mind doesn't send questions to Jev as requests. Everything notable becomes an `Event`, which the face reacts to and the minds read. `nature.rs` holds its five inborn traits (playful, curious, shy, sleepy, tender), rolled from the world's random source and kept in `Life::nature`; `Nature::leaning` moderately tints instinct, while nature also changes need rates, naps, greetings, bond growth and retention, and the words its minds use. Seeded worlds roll a nature at creation, `begin_life` supplies one if absent, and `app::restore` derives a missing nature from `Save::born`. `life.rs` is the ghost's life over days (`World::life`, saved): `Life::note` counts each recorded event in a `Tally` for today and for all time and warms or cools its `bond` with the viewer, `pass` deepens the bond while the viewer is present, `miss` fades it after days away (never below half of `closest`), `habit` turns how often it chose each activity into a weight multiplier for `instinct::weigh`, and `begin_day` writes yesterday's tally into the `diary` in words. `note` and `pass` return a milestone when a first or a landmark is reached (kept once in `milestones`, written in words without digits since it reaches the minds as `EventKind::Milestone`, which `record` adds right after the event that caused it). `Life` also saves `bird_trust`, the newest eight `keepsakes` (a `Keepsake` enum), and a gift on the outer `sill`; `sanitized`, called by `app::restore`, clamps trust and trims the shelf. `Kept` counts gifts and their kinds for the diary, and the first gift and crossing into the bird's trust are milestones. Once the bond reaches `Life::greeting_bond` (near `GREETS_FROM`, tinted by nature), the ghost comes to greet an arriving viewer (`greet`). `sight.rs` gives the ghost a `heading` that turns at a limited rate (`look_around`) toward its `attention` (a `Thing` a mind chose with `attend`, or a mote the viewer dropped), else its plan's `look`, else its motion, else a slow wander. `World::sight` lists the `Thing`s within sixty degrees of the heading, with their distance, side, height, and any furniture hiding them, and what it looks at. Motes count as known only once seen (`ghost.known`; dropped ones at once), and only known motes can be chased. `calendar.rs` maps the date to a northern hemisphere `Season` and the mean moon phase. `weather.rs` runs seasonal clear spells and showers: some spring, summer, and autumn showers are thunderstorms, with seeded lightning schedules and delayed thunder that makes the ghost flinch, sometimes wake, and seek a trusted viewer or favor its cushion; winter brings snow, which builds cover on the hills and melts more slowly at night; daytime rain leaves a rainbow. Its `Change`s become events, and first seeing a rainbow or snowfall through the window records `Noticed`. `visitor.rs` schedules passing company with the world's random source: a shy bird perches outside the window on dry days (less often in snow), and a moth circles the lit lamp at night and darts away from a close ghost. Each is noticed once per visit through sight, remembered in the life tally, and never caught. Quiet, settled Window watching earns the bird trust slowly; startling it loses trust. Trust shortens visit and song intervals, softens startles, and favors the sill perch. An unstartled trusting bird may leave a seasonal `Keepsake` with `GiftLeft`; the ghost reacts only once it sees the gift through the window. Window plans reach through the pane to take it, carry it below the ghost, and place it on the shelf (`Kept`). Interruptions settle carried gifts at once; `World::saved_life` settles them in the saved snapshot too. The wooden shelf at `SHELF_POSITION`, left of the window above the lamp, is `Thing::Shelf` (mind name "shelf"); gifts waiting outside use `SILL_POSITION`. Seeded worlds start on 2026-06-21; live worlds follow the local date and hour.
- **`world/sleep.rs`** defines bedtime, from 22:00 until 06:30 local time, separately from the lighting night. Rest plans begun then are `overnight`: they stay asleep even with full energy until morning, recording `WokeUp` and `Morning`, a stretch, and a small upward bob. `Morning` counts a night in `Tally` and starts ten minutes of favoring the window and greeting a present viewer. Instinct favors bed more strongly when the viewer is away, turning off the lamp first; company softens that pull. `wake` leaves an interrupted night drowsy for two minutes, below delight, annoyance, or a mind's mood suggestion. `App::live` calls `tuck_in` at bedtime after restoring, without another `FellAsleep`; merely noticing a viewer never wakes a sleeper. Naps still end when rested. These sleep timers and plans are not saved.
- **`world/routine.rs`** lets an awake ghost wait at the glass near the viewer's usual visiting hours, with a slow side-to-side drift and occasional glances at the window. `Life::arrive` learns each local hour at most once a day, `begin_day` decays the saved weights and their day normalizer for each day passed, and `expectation` smooths neighboring hours after arrivals on three different days. `usual_time` names the strongest hour in words and first learning it is a milestone. Arrivals satisfy a whole expected window, including an early arrival while waiting; `ExpectedArrival` brings a greeting, delight, and a heart. Consecutive expected hours share one visit; after an expected hour spent waiting passes, `MissedVisit` brings a lonely thought and an open heart at most once for that whole window. Both events count in `Tally` and the diary. `World::step` notes missed visits before beginning the new diary day; fixed seeded hours never close a window. The life panel and both minds hear when the viewer usually comes, and offline thoughts and dreams follow waiting and visits too. Only the learned routine and arrival bookkeeping are saved, not waits.
- **`world/blocks.rs`** holds five seeded toy cubes, recreated each session, and the `Build` activity: gather, carry, stack with seeded jitter, retreat to admire, then sometimes swoop to topple according to playfulness. Held cubes follow the ghost and drop on interruption. Loose cubes use short physics slices for gravity, damped floor and wall bounces, furniture collisions, tumbling, face settling, and pair separation; the ball bounces off their floor circles and a fast hit topples a tower. `World::topple` releases its levels with seeded spread and spin; clicks flick loose blocks or topple a tower, delighting a playful ghost or a trusted friend and otherwise making it grumpy. A standing tower steers the ghost around it except when placing or swooping; `Thing::Blocks` locates it or the nearest loose cube, and a tower at least three high hides things behind it. `Built` and `Toppled` reach the face, emotes, and minds in words; defaulted `Tally::towers`, `tallest`, and viewer `toppled` counts persist, with first-tower and five-high milestones, diary phrases, life-panel counts, and offline thoughts and dreams. Blocks are rounded boxes marched inside individual bounding spheres in `render/shapes.rs`.
- **`world/doodle.rs`** holds the pictures drawn in fog on the glass. `Picture` is a `Sketch` or a `Word` (`Writing`, whose measured path is shared with `Arc`); both reuse polylines with pen lifts, length, pen position, partial distance, and extent. `letters.rs` supplies strokes for uppercase Latin letters, digits, punctuation, and a heart. Words are centered, about a fifth of a room unit tall, and shrink to fit the glass. `choose_picture` sometimes picks BOO at Halloween, the coming year at New Year, YAY on birthdays, a close viewer's name with a heart when it fits (a heart for other scripts), or HI after a friend's arrival; Valentine otherwise keeps hearts. `World::write` sanitizes a requested word to eight supported characters and begins drawing only while awake with energy. `Doodle` times drawing (at least four seconds, longer for long words) and fading; the world keeps the newest three. `Wrote` counts in `Tally::writings`, keeps a few words for the diary, and counts watched words separately in `watched_writings`. The first three watched words are mirrored; the first word written the viewer's way afterwards marks a milestone once. Written digits are spelled out in descriptions for the minds. Hiding eases `Ghost::fade` until a click finds it or its wait ends in a jump toward the glass.
- **`world/game.rs`** holds a game of noughts and crosses in fog on the glass (`World::game`, not saved). `Game` keeps reading-order cells, cross and nought stroke times, turns, and the outcome; its rules and depth-weighted minimax stay in code. `Activity::Game` wipes doodles centered on its board, draws the grid, then alternates the viewer's crosses with noughts the ghost thinks over, approaches, and draws. `challenge` (`g`) gives an awake viewer the opening move; a game the ghost starts opens with its own nought. `mark` accepts a free cell only after the grid is finished and during the viewer's turn; board clicks and keys `1`–`9` call it. All move choices, thinking times, mistakes, and result speech use the world's `Random`; curiosity improves play, playfulness and low energy soften it, and tenderness adds gentleness with a close bond. Games wait past the generic plan timeout but abandon a viewer's turn after forty-five seconds; other interruptions abandon silently. `GameOver` records finished results or viewer timeouts; finished games warm the bond, count games, wins, losses, and draws in `Tally`, and keep first-game, first-win, and first-loss milestones. Wins delight, losses bring cheer or grumpiness according to tenderness and bond, and draws bring curiosity. The board shares `doodle::Path` stroke math, draws a winning line, lingers briefly, and fades over forty seconds. Observations describe turns and immediate winning threats in words; offline thoughts and dreams recall games.
- **`world/occasion.rs`** names special days, with priority Birthday > NewYear > Halloween > WinterHolidays > Valentine: Halloween runs October 24–31, winter holidays December 18–30 and December 31 before 20:00, New Year from December 31 at 20:00 through January 1, and Valentine's Day on February 14. Birthdays start at the first anniversary of `World::birthday`, set from the saved birth timestamp in local time by `App::live`; February 29 becomes February 28 in other years. Seeded pictures have no birthday unless `--born` sets one. A temporary `Decoration` at the back right is furniture, an obstacle, and `Thing::Decoration` (mind name "decoration"), present for every occasion except Valentine. Halloween favors hiding, birthdays favor dancing and cheerfulness, and Valentine makes pink motes and heart doodles. Fireworks run from December 31 at 23:30 to January 1 at 01:00; stateless bursts in `render/window.rs` also tint `light_through`. `Celebrated` is recorded once per occasion day and again at midnight, sparkles in the face and emotes, and is counted in `Tally::celebrations` with occasion phrases in the diary. Celebration tracking is not saved. The observation names the occasion and birthday ordinal in words; offline thoughts and dreams follow it too.
- **`mind/`** runs the models on a background tokio runtime; answers come back over an mpsc channel and `Mind::think` applies them each frame, so the world never waits. When a plan ends, Jev gets the observation and two Choice questions (`decision.rs`); its activity probabilities are blended with `instinct::weigh` (code keeps control) and sampled with the world's random source. After 2.5 s without an answer, or without a key, instinct decides alone, and late answers are dropped by id. A viewer's message goes to the world's `hear` first, then to Jev as a request-routing Choice (`play`, `rest`, ... or `none`, applied through `World::heed`, which also teaches the ghost the words; without Jev, `World::guess` tries out a repeated unknown word) and to Claude for a reflection (`reflection.rs`: the persona, memories, latest milestones, the last few diary days, and the words it has learned as the system prompt, a JSON schema, and one user message with the conversation and then the observation). Reflections also run on a timer (`reflect_every`, five times slower while the viewer is away). Without Claude, `musing::reply` answers the viewer in a few words about what it made of their message (naming the word it understood or wonders about), and `Mind::muse` gives the ghost thoughts of its own from `musing.rs` (lines that fit the moment: as it sets out on an activity, idle musings every minute or so, and dreams woven from today's `Tally` while asleep), picked with the world's random source. `observation.rs` describes the world in words, never numbers, because Jev judges words far better, including the weather outside and the ghost's `sight` (where it faces, what it looks at, what else is in view and where). A reflection's `look_at` turns the ghost's gaze for a while, and its optional `write` string requests a short word through `World::write`. Observations and the reflection's system prompt include the known viewer name; offline replies acknowledge introductions in English or Korean and sometimes greet the viewer by name. `jev.rs` and `claude.rs` are raw-HTTP clients (Rust has no official SDKs) with retries, `retry-after`, and keys redacted from errors and `Debug`. Claude requests use structured output (`output_config.format`), an optional `effort`, prompt text as `Block`s that may carry a cache marker (`Cache`, 1 hour by default: the persona and memories in `system`, then the conversation, with only the observation uncached), and `fallbacks: "default"` with beta header `server-side-fallback-2026-07-01` except for Haiku models (`offers_fallbacks`). A 400 is retried once as a plain request without effort, fallbacks, or cache markers, so any model works without a capability table. No `thinking`, `temperature`, or prefill (they 400 on current models). The model, effort, and cache come from `Config` and change at runtime through `Mind::reconfigure`; requests already sent finish with the old settings.
- **`face/`** is the face rig and what drives it. `Face` holds the controls (gaze, per-eye shut and lid, slant, widen, smile, sparkle, prompt, cursor), `Face::distance` is its signed distance (eyes cut out of the head; each feature morphs by moving its own points), `lerp` blends faces and `layer` adds one's departures from rest to another. `expression.rs` has the expressions (Blink, Glance, Smile, Sparkle, Prompt, Doze, Glare, ...), each a function of the time since it started that begins and ends at `Face::REST`. `mood.rs` gives each `Mood` a held base face and a repertoire it picks from per time slot by a hash of the slot (irregular but stateless), then lays on the gaze, sleep, blinks, and reactions to recent events (`reaction`). `emote.rs` turns moods and recent events into at most three wordless symbols rising over the head, using deterministic beats and hashed time slots; `ui.rs` draws them beside speech bubbles.
- **`render/`** ray casts each pixel (`Frame::sample`, parallel). `Camera` orbits the room's center; `View` gives rays (`ray`), projects points (`project`), and finds where a screen point meets the floor, the glass, or the ghost (`on_plane`, `on_glass`, `touches_ghost`). Rays pass through the near walls and show the far ones (`room_exit`, `room_color`: dot lattices with dashed edges, glass showing only edges). The back wall has a wooden window (`render/window.rs`), a picture of seasonal hills and a tree, with spring blossom, autumn leaves, bare winter branches, drifting clouds, stars, the sun, the moon with its calendar phase, rain, rainbows, snowflakes and snow cover, and summer fireflies. Its broad sky light also lights the room, brightened coolly by snow cover. The bird and any gift on the outer sill are drawn into the window picture; the wooden keepsake shelf and each carried or shelved gift use bounded signed distance fields in `shapes.rs`. The moth is a small warm-lit body with fluttering wings in the room. The ball is a sphere; furniture (`shapes.rs`) is signed distance fields marched inside bounding spheres. The ghost is a camera-facing billboard (`ghost.rs`): `Pose` leans and trails its hem with its screen-space velocity, `shade` draws the body as a lattice of dots when there is room and the ring in the aura's color, pulsing with its beat. The aura carries visibility while hiding: the body, ring, and room light fade, leaving faint eyes. Doodles and game boards overlay rays crossing the glass from either side, with bounds checked before stroke distances. Lights: daylight by hour, the lamp, the ghost's glow, and the motes. Styles other than braille supersample 2x.
- **`settings.rs`** is the settings panel's state (`Settings`, opened with `k`): the two keys (empty keeps a key, `-` removes it), the Claude and Jev models (←/→ step through presets, any name can be typed), effort, and cache. `apply` writes it into the `Config`; the app then saves the file and reconfigures the mind.
- **`app.rs`** holds the UI state and turns input into actions: commands while watching, a `Line` editor while talking, the settings panel, clicks (active board cells take priority, then ghost pokes, block flicks or tower toppling, ball flicks, elsewhere drops a mote), drags (a drag begun on the ghost strokes it through `World::pet` and leans the pose into the hand; any other drag orbits), and the wheel (zoom). Mouse motion calls `World::point_at` with where the pointer meets the glass, keeping `Viewer::liveliness` (recent travel, fading exponentially) and `moved_at`; a darting pointer invites an awake, playful ghost to chase and pounce along the inside of the glass. The journal opens at the bottom and stores its scroll as a distance from the bottom: Up/Down move a line, PageUp/PageDown a viewport, Home/End to either end; Esc, Enter, and `j` close it, `q` quits, and other keys do nothing. Help closes on any key except `q`, which quits. `wants_mouse` releases the mouse in the journal, help, and life panels so the terminal can select text and handle the wheel (often sent as arrow keys). `l` opens the life panel (age, nature, bond, viewer name, favorite activity, bird friendship and keepsakes, lifetime counts, today so far), which closes on any key like help. `p` saves the last watching frame's scene and words line as a postcard through `postcard.rs`, without the status bar or panels; without a save path it posts that postcards need a saved life. Plain blocks keep a truecolor copy of the same sampled frame for ANSI postcards. It builds the face cues (gaze to the pointer while it moves, else to what the ghost looks at), the aura (mood color eased over time), and the pose. `restore` starts the world from a save, aging it by the time away. `live` makes it a running life that saves every minute.
- **`ui.rs`** draws the speech bubble above the ghost, the words line (typing, notices, speech, thought, goal), the status bar (with the Claude model's short name), and the help, settings, and journal panels. `JournalPanel` wraps all memories, the diary, the whole retained conversation, the latest ten events, and model errors, indenting continuation lines under their text. Its viewport is shared by drawing and scroll keys; drawing clamps the scroll after content or size changes. Border arrows and a visible line range show overflow, and tiny screens are safe. `write` handles wide characters (Hangul and others take two cells; the second is `Cell::CONTINUATION`, which writes nothing).
- **`store.rs`** keeps `Config` (keys, models, effort, cache, `reflect_every`, base URLs) in `$XDG_CONFIG_HOME/wave-ascii/config.json` and the `Save` in `$XDG_DATA_HOME/wave-ascii/ghost.json`, written atomically with mode 0600 in a 0700 directory. `Paths::postcards` puts postcards beside the saved life; `postcard.rs` reuses its private directory creation for timestamped `.txt`/`.ans` pairs, adding a suffix on collisions. `ANTHROPIC_API_KEY` and `TYPESAFE_API_KEY` override saved keys without being saved. Keys never appear in `Debug` output (`mask`).
- **`terminal.rs`** uses crossterm: raw mode, the alternate screen, mouse capture, and bracketed paste, all undone on drop, so code must let `Terminal` drop normally instead of calling `process::exit`. Capture starts on; `Terminal::set_mouse_capture` tracks its state and only writes escapes when it changes. Journal and help release capture for native text selection, and closing them restores it. Drop always disables capture. It pushes the user's title on open and pops it on drop; `set_title` writes only when the ghost's name and activity change, using “asleep on the cushion” during sleep. Piped mode never opens a terminal or sets its title. `Input::from_event` maps events to `Key`, `Paste`, `Mouse`, and `Resize`. Frames are wrapped in synchronized-output markers (`?2026`).
- **`frame.rs`**, **`canvas.rs`**, **`color.rs`**, and **`sdf.rs`** are the drawing basics: `Grid` (pixel lattice; y from -1 to 1, `CELL_ASPECT = 0.5`), `Shade` and `Frame`, the three styles (ascii ramp, `▀` blocks, 2x4 braille), color modes and their detection, and 2D signed distance helpers (`coverage`, `capsule`, `trapezoid`, `star`, ...).
- **`main.rs`** parses options, prints the piped frame, or loads the config and save, builds the `App`, runs the loop at `--fps` (inputs wait until the next frame; a redraw request is kept until that frame), and saves on quit. After each input batch it calls `terminal.set_mouse_capture(app.wants_mouse())` before waiting for the next frame.

### Notes

- The world and minds must keep code in control: Jev answers narrow typed questions about words (Jev's own docs: keep numbers, distances, and dates in code; options in a fixed order matter), and its choices are blended with instinct. Claude only adds thoughts, words, goals, a mood suggestion, memories, and a name.
- When adding an activity: the `Activity` variant, `name`/`doing`, `World::begin` (target and length), `carry_out` (what happens and when it's done), `options`/`describe`, `instinct::weigh`, `decision::request` (what asking for it sounds like), and the README.
- When adding a thing the ghost can see: the `Thing` variant and its `name` (and `Thing::NAMES` if minds may turn to it), `World::position_of`, `World::sight`'s list, `observation::thing` (how it reads), and `blocker` if it hides what's behind it.
- When adding an event: `EventKind` and its `words`, where the world records it (weather changes pass through `World::advance`), `face::mood::reaction` if the face answers it, `face::emote` if it should puff a symbol, and `Tally::note` (with a `Tally` field and a phrase in `Tally::words`) and `Life::note` if it should count in the ghost's life or touch its bond. Snow and rainbow notices sparkle only once the ghost sees them through the window.
- Art direction: everything is drawn from code; colors stay mid to bright so plain styles keep contrast. The user checks visuals; don't write tests that assert how things look.

## Conventions

- Tests are inline `#[cfg(test)] mod tests` blocks. Test names are descriptive sentences in snake_case, for example `a_rolling_ball_stays_in_the_room_and_comes_to_rest`. Test behavior and computation (input, the world's rules, the minds' requests and answers, math), not appearance.
- Identifiers are full words (`columns`, `rows`, `distance`), not abbreviations.
- Commit subjects are concise and imperative, for example `Add wave rendering module`. For changes that affect visible output, include sample terminal output in PRs. If tests could not be run, say so explicitly.
- When adding tooling or commands, document them in `README.md`.
