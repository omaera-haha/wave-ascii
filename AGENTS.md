# AGENTS.md

This file provides guidance to coding agents such as Codex when working with code in this repository. It mirrors CLAUDE.md; keep the two in step.

## Overview

`wave-ascii` is a Rust (edition 2024) terminal app in which a ghost lives in a glass box. The box is a 3D room drawn as text (dots, dashed edges, a lamp, a plant, a ball, toy blocks, a music box, a cushion, drifting light motes). The ghost is a point with a body, needs, a mood, and a plan, drawn as an abstract shape of dots whose glow and face show its state. Two models give it a mind: Jev (TypeSafe's System One model) picks what it does next, and Claude (System Two) reflects, sets goals, remembers, and talks. Without keys it runs on instinct. Dependencies: `crossterm` (terminal), `glam` (math), `tokio` and `reqwest` (API calls), `serde`/`serde_json`, `jiff` (local time), `unicode-width` (wide characters).

## Commands

The Rust toolchain lives in the dev container (`.devcontainer/`, based on `rust:latest`, which adds rustfmt and clippy). The host may not have `cargo` installed.

```bash
cargo check
cargo test
cargo test world::tests::      # one module's tests
cargo fmt --check
cargo clippy --all-targets
cargo run --release            # interactive; --style, --color, --fps, --offline, --help
cargo test --release audit -- --ignored --nocapture   # three simulated days: pacing report
AUDIT_DAYS=40 cargo test --release audit -- --ignored --nocapture   # a longer life, for pacing over weeks
```

`src/audit.rs` holds that report: a seeded ghost lives offline beside a simulated viewer (mornings, lunch, evenings), and it prints activity shares, plan lengths, event counts, repeated thoughts, the diary, milestones, and each day's bond, milestone count, and library size, with the timeline in the temporary directory. Use it after changing rates, plan lengths, or instinct weights; for a grown ghost, aim for a few naps and a couple of rainbows a day rather than dozens.

When stdin or stdout isn't a terminal, the app prints one frame of a fresh, seeded ghost and exits. It never touches saved files or models. The frame size comes from `COLUMNS`/`LINES`. `--time` runs the world that long first (instinct decides), `--hour` sets the time of day (default 12), `--date YYYY-MM-DD` sets the date (default 2026-06-21), and optional `--born YYYY-MM-DD` sets its birth date for birthday and day-of-life previews, so a given `--time`/`--hour`/`--date`/`--born` always gives the same frame:

```bash
COLUMNS=100 LINES=32 cargo run -q -- --time 20 < /dev/null | cat
COLUMNS=100 LINES=32 cargo run -q -- --date 2026-09-26 --hour 20 --time 400 < /dev/null | cat
COLUMNS=100 LINES=32 cargo run -q -- --style blocks --color truecolor --hour 21 < /dev/null | cat
COLUMNS=100 LINES=32 cargo run -q -- --date 2026-12-24 --hour 22 --time 400 < /dev/null | cat
COLUMNS=100 LINES=32 cargo run -q -- --date 2027-03-01 --born 2026-03-01 < /dev/null | cat
COLUMNS=100 LINES=32 cargo run -q -- --date 2026-06-10 --born 2026-03-03 < /dev/null | cat
COLUMNS=100 LINES=32 cargo run -q -- --date 2027-02-07 < /dev/null | cat
COLUMNS=100 LINES=32 cargo run -q -- --date 2026-09-25 --hour 21 < /dev/null | cat
```

To exercise the interactive loop, run it under `script` with a pty and feed input on stdin. Point `XDG_CONFIG_HOME`, `XDG_DATA_HOME`, and `HOME` at a scratch directory so the real save isn't touched, for example `(sleep 1; printf q) | XDG_DATA_HOME=/tmp/x XDG_CONFIG_HOME=/tmp/x HOME=/tmp/x script -qfec "stty rows 34 cols 110; ./target/release/wave-ascii" /dev/null`. Feed mouse input as SGR reports with 1-based cells: `printf '\033[<35;50;12M'` moves the pointer to column 50, row 12; `'\033[<0;50;12M'` and `'\033[<0;50;12m'` press and release the left button; `'\033[<32;55;12M'` drags; `'\033[<64;50;12M'` scrolls.

No API keys are available in the dev container; the clients and the mind are tested against local mock servers.

## Architecture

Each frame: `App::advance` steps the `World` and lets the `Mind` act on it, then `App::frame` builds the face, aura, and pose, calls `render::render` (a `Frame`), turns it into a `Canvas` with `Style::canvas`, and `ui::draw` adds words and panels. `Terminal::draw` writes the changed cells.

- **`world/`** is the simulation, deterministic for a seed (`Random`, SplitMix64). The room is the box `ROOM_MIN`..`ROOM_MAX`, floor at y = 0, glass front facing +z. `World::step` moves in slices of at most 0.1 s: motes drift, spawn, and expire; the ball rolls and bounces or follows the ghost while held; the plant gets thirsty; the ghost carries out its `Plan` (`carry_out`), steers toward the plan's target around obstacles and away from walls (`move_ghost`), and its `Needs` (energy, fun, company, 0 to 1) change. Its `Mood` comes from a mind's suggestion while it holds, otherwise from needs and recent events (`feeling`). `Activity` is what a plan does (float, explore, chase, rest, play, tend, lamp, visit, window, fetch, dance, hide, doodle, pounce, game, wait, build, friend, look, company, air, puzzle, read, music, mirror, letter, comfort); minds only choose one through `begin`, from `options()` (what makes sense now), and `describe` words each option. Viewer actions are methods: `poke`, `pet`, `drop_mote`, `kick_ball`, `nudge_block`, `hear`, `point_at`, `challenge`, `mark`, `poke_friend`, `draw_on_glass`, `lift_finger`, `wind_music_box`. `pet` takes how far a stroke moved across the ghost; petting fades within seconds, soothes it to cheerful, adds company, slows its movement, makes the face blissful and puff hearts, never wakes a sleeper, finds a hidden ghost, and records `Petted` once per spell. `vocabulary.rs` reads a message's tone (greeting, farewell, praise, or a no, in English and Korean) and its other words, and keeps the `Vocabulary` (saved in `Life`): evidence for what each word means, learned from the activity the ghost was doing when it heard the word, what the viewer did next (a ball flick means fetch, a dropped mote chase), praise or a no after it acted on the words, and `heed` (a mind's request routing); a word means an activity once its evidence is strong and clear. `introduced_name` recognizes English and Korean introductions without a model, keeps the viewer's name in `Life::viewer_name`, and records `LearnedName` with a first-name milestone; introductions do not teach activity words. `given_name` recognizes the viewer naming the ghost ("your name is Pip", "I'll call you Pip", "너의 이름은 뽀삐야", "뽀삐라고 부를게"; not questions or "call you later"); `World::take_name`, which a reflection's `name` also goes through, renames it and records `Named` with a first-name-given milestone, and such messages teach no words and ask no question. `hear` returns a `Heard` (tone, `Understanding`, words, viewer name, and given name just learned) and acts on a known word if it can, else comes to the glass; a no stops the current plan. `guess` tries out what a repeated unknown word might mean. `question.rs` recognizes simple questions about the ghost (feeling, doing, name, the viewer's name, liking, age, favorite, weather, tired, hungry, bored, lonely, shelf, bird, friend, books being read, favorite books, music, known songs, the mirror reflection, and `Question::Story` or reading-aloud requests; English word runs and Korean pieces, some needing a question mark); `hear` then returns `Understanding::Asked` with what it was doing (or `None` if asleep), learns nothing from the words, ignores praise words in them, and comes to the glass; `musing::reply` answers from the ghost's state (in Korean when `Heard::korean`), and the mind doesn't send questions to Jev as requests. Everything notable becomes an `Event`, which the face reacts to and the minds read. `nature.rs` holds its five inborn traits (playful, curious, shy, sleepy, tender), rolled from the world's random source and kept in `Life::nature`; `Nature::leaning` moderately tints instinct, while nature also changes need rates, naps, greetings, bond growth and retention, and the words its minds use. Seeded worlds roll a nature at creation, `begin_life` supplies one if absent, and `app::restore` derives a missing nature from `Save::born`. `life.rs` is the ghost's life over days (`World::life`, saved): `Life::note` counts each recorded event in a `Tally` for today and for all time and warms or cools its `bond` with the viewer, `pass` deepens the bond while the viewer is present (all warmth fills only the room the day has left, `Life::warmed` against `DAILY_WARMTH`, and slows with the square of the remaining distance, so devotion takes many weeks), `miss` fades it after days away (never below half of `closest`), `habit` turns how often it chose each activity into a weight multiplier for `instinct::weigh`, `novelty` damps pastimes (music, mirror, doodles, hiding, building, dancing, exploring, play) already begun often today so a day holds variety, and `begin_day` writes yesterday's tally into the `diary` in words, keeping only the six deeds that stood out most (`Tally::diary`, ranked by a `Salience` from routine to momentous, most notable first), while `Tally::words` keeps the full account for the life panel's today so far. `note` and `pass` return a milestone when a first or a landmark is reached (kept once in `milestones`, written in words without digits since it reaches the minds as `EventKind::Milestone`, which `record` adds right after the event that caused it). `Life::korean` saves an exponential average of the viewer's language, moving a third of the way toward Korean or other lettered speech in `hear`; punctuation leaves it alone, `speaks_korean` is true above half, and `sanitized` clamps it. Spoken lines keep English and Korean counterparts together and follow this language; offline replies also answer a Korean message in Korean at once, while thoughts stay English. `Life` also saves `bird_trust`, the newest eight `keepsakes` (a `Keepsake` enum), and a gift on the outer `sill`; `sanitized`, called by `app::restore`, clamps trust and trims the shelf. `Kept` counts gifts and their kinds for the diary, and the first gift and crossing into the bird's trust are milestones. Once the bond reaches `Life::greeting_bond` (near `GREETS_FROM`, tinted by nature), the ghost comes to greet an arriving viewer (`greet`). `sight.rs` gives the ghost a `heading` that turns at a limited rate (`look_around`) toward its `attention` (a `Thing` a mind chose with `attend`, or a mote the viewer dropped), else its plan's `look`, else its motion, else a slow wander. `World::sight` lists the `Thing`s within sixty degrees of the heading, with their distance, side, height, and any furniture hiding them, and what it looks at. Motes count as known only once seen (`ghost.known`; dropped ones at once), and only known motes can be chased. `calendar.rs` maps the date to a northern hemisphere `Season` and the mean moon phase. `meteor.rs` places shooting stars on dark (20:30 to 05:00), clear nights: each ten-second slot holds one by a SplitMix hash of the world's seed and the slot (stateless, so it never draws from `random`), far more often on the evenings of the yearly showers (`shower`, with the small hours counting for the evening before); `World::shooting_star` is the one crossing the sky now, `Outside::meteor` draws its `Streak` in the window, and a ghost that sees it through the window records `ShootingStar` once per star and thinks a wish (counted in `Tally::shooting_stars`, a first-star milestone; instinct favors the window on shower nights). `weather.rs` runs seasonal clear spells and showers: some spring, summer, and autumn showers are thunderstorms, with seeded lightning schedules and delayed thunder that makes the ghost flinch, sometimes wake (at most once a storm, `storm_woke`), and seek a trusted viewer or favor its cushion; clear spells last one to five hours (seasonally scaled) and showers five to twenty minutes; winter brings snow, which builds cover on the hills and lingers for hours in winter, melting more slowly at night; about a third of daytime showers leave a rainbow. `world/forecast.rs` lets an awake ghost feel a scheduled shower four to eight minutes ahead (sooner when curious), noticing only some by a SplitMix hash of the shower's time so it never draws from `random`: it thinks it, tells a present viewer it knows in their language, and when the rain or snow begins within a quarter hour records `ForecastCameTrue` (sparkle, counted in defaulted `Tally::forecasts`/`snow_forecasts` with a diary phrase and a first milestone); observations say what it feels coming. Its `Change`s become events, and first seeing a rainbow or snowfall through the window records `Noticed`. `visitor.rs` schedules passing company with the world's random source: a shy bird perches outside the window on dry days every twelve to thirty minutes (sooner with trust, less often in snow), and a moth circles the lit lamp at night and darts away from a close ghost. Each is noticed once per visit through sight, remembered in the life tally, and never caught. Quiet, settled Window watching earns the bird trust slowly; startling it loses trust. Trust shortens visit and song intervals, softens startles, and favors the sill perch. An unstartled trusting bird may leave a seasonal `Keepsake` with `GiftLeft` on a day it decides, once a day, to bring one (`gift_chance`, about two days in five at full trust), never twice in a day, with the day's decision saved in `Life::gift_decision` so restarts neither repeat nor reroll it; the ghost reacts only once it sees the gift through the window. Window plans reach through the pane to take it, carry it below the ghost, and place it on the shelf (`Kept`). Interruptions settle carried gifts at once; `World::saved_life` settles them in the saved snapshot too. The wooden shelf at `SHELF_POSITION`, left of the window above the lamp, is `Thing::Shelf` (mind name "shelf"); gifts waiting outside use `SILL_POSITION`. Seeded worlds start on 2026-06-21; live worlds follow the local date and hour. `world/dream.rs` holds an unsaved `World::dream`: `Mind::muse` starts its picture from the first matching word in a dream line (including its friend's name), falling back to a moon. It holds for twelve seconds, grows in over one and a half, fades over the last two, and clears on waking; cached unit-box strokes reuse doodle paths and sketches.

## Conventions

- Tests are inline `#[cfg(test)] mod tests` blocks. Test names are descriptive sentences in snake_case, for example `a_rolling_ball_stays_in_the_room_and_comes_to_rest`. Test behavior and computation (input, the world's rules, the minds' requests and answers, math), not appearance.
- Identifiers are full words (`columns`, `rows`, `distance`), not abbreviations.
- Commit subjects are concise and imperative, for example `Add wave rendering module`. For changes that affect visible output, include sample terminal output in PRs. If tests could not be run, say so explicitly.
- When adding tooling or commands, document them in `README.md`.
